# Idea

## Pitch

Everything as code, pointed at project management. Kanbus keeps issues (tasks, bugs, the rest) as files in the GitHub repo, usually a pile of JSON, instead of a separate PM product.

That is simpler in a lot of ways. No new SaaS. No new integration. No new auth. Agents and humans already have the repo. Git is the bus.

## Audience

Teams already living in git who are tired of Jira/Linear/Asana as a second system their agents cannot see without another connector.

## Working title

Kanbus: project management as code

## Split

Distinct from:
- `0bf71a` DeckBot / EaC intro (slides as Markdown, Marp, Terraform, Playwright)
- `f10464` hill-climbing / Plexus (classifier DSL, AlphaEvolve, Autoresearch)

This piece is EaC applied to the issue tracker.

## Agent-first

Point a coding agent at a repo and it already has all the project-management information it needs, right there in the repo. Simple. You can start filing new tasks instantly by telling the bot to do it.

There is a human UI too: the web console. The whole system is AI-first design, which means everything as code.
