# Assignment

Write an Anth.us article that ties everything-as-code to Kanbus: project management as code.

## Gist

Using files in the GitHub repository to track project-management issues (tasks, bugs, and the rest) is in many ways a lot simpler if it is just a pile of JSON files in the code repo, rather than an external system that requires new integrations, authentication, and so on.

## Must

- Kanbus is the example. GitHub / git is the store.
- Contrast: external PM (Jira, Linear, Asana, etc.) needs connectors and auth. Files in the repo do not.
- Point a coding agent at a repo and it already has all the project-management information it needs, right there. Simple.
- You can start filing new tasks instantly by telling the bot to do it.
- There is a human UI: the web console. The system is AI-first design, which means everything as code.
