# Idea

## Pitch

RubyHack documents a May 2026 RubyGems package flood that apparently used automatic RubyDoc builds to fetch public web data and publish it back as gems. The claim that OpenAI agents authored the malicious packages is contested by RubyGems. A short post can explain the infrastructure lesson while separating findings from attribution.

## Audience

AI engineers and teams giving agents access to package registries and build services.

## Working title

The Package Registry Became a Data Channel
