# Idea

## Pitch

A knowledge base should be files a person can open, not a pile an agent searches. When the agent writes a page overnight, that page is a draft until a person says it belongs. When a fact is replaced, the old page is marked dead. We do not delete the trail, and we do not treat the pretty wiki as proof. Proof is the original source. When a number has an official recipe, the agent may fill in this year. It may not change the recipe. A dumb checker, not another AI, catches a swapped table name. We are not building a smarter chatbot. We are building a wiki that can say this is live, this is an agent draft, and this is yesterday's definition, do not use it.

The villain is a wiki that only gets bigger. If last night's agent can keep adding pages, and nothing ever gets marked dead, you do not have a knowledge base. You have a dump with nicer headings.

## Audience

People running agent research desks and internal wikis who are watching the pile grow and calling it a knowledge base.
