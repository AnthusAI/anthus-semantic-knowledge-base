Write a public Anth.us essay: the change-management receipt for agent-written commits. Metaphor: an inspector's produce sticker. You cannot put the crate on the truck without the mark.

Working title: Inspected-by sticker. Ryan may rename.

This is a hire-path piece. Proof that we already run agent factories with a gate, not a product launch and not a ninth homepage card.

## Spine

1. Agents ship overnight. `--no-verify` is the easy path. Human-read-every-diff is dead as SOC 2 theater.
2. Produce-sticker test: can you put this on the truck without the inspector's mark? If yes, it is not this idea.
3. The sticker has to name a pinned, deterministic validator (not the LLM), this git tree, and be required at deploy.
4. Skip is the process hole, same class as shipping without a change ticket.
5. We built that. Name it Pudicus once, after the metaphor lands. Hook, HMAC receipt, deploy gate. Scanners are pluggable.
6. The agent cannot mint the sticker, so the easy path is letting the hook run.
7. Cover art is the produce sticker (inspected-by-sticker-cover.png in this story folder).
